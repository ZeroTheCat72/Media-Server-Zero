# How to use

The project runs on port 3001, preferably LAN, I don't believe its secure otherwise. Any files you want put them inside root, make your own folders inside, whatever. The pictures, music, and movie folders are used to present content the moment you open the site.

The movies folder also has an artwork folder inside, so if you have a movie and an artwork, make sure they have the same name. (with different extensions of course.)
